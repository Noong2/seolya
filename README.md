# 설야 · 雪夜

눈 오는 밤, 잠시 쉬어가는 3D 오두막.

## 방문하기

https://noong2.github.io/seolya/

설치나 로그인 없이 브라우저에서 실행됩니다. WASD·방향키·바닥 클릭으로 이동하고, V로 1인칭과 3인칭을 전환할 수 있습니다. 모바일에서는 이동 패드를 사용합니다.

## 무료 운영

이 저장소는 브라우저에 전달할 정적 파일만 포함합니다. GitHub Pages 기본 주소를 사용하며, 유료 서버·데이터베이스·AI API·사용자 결제는 연결하지 않습니다. GitHub Pages의 무료 서비스 한도와 이용약관이 적용됩니다.

## 리소스 출처

- 장작 및 마시는 소리 — CC0. 원본 링크와 설명은 `assets/audio/CREDITS.md` 참조.

- 캐릭터·오두막·겨울 지형·숲·불꽃·핫초코는 코드로 구성됩니다.

## 수정 배포

`main` 브랜치의 루트 정적 파일을 GitHub Pages가 배포합니다. `.nojekyll`은 정적 파일을 그대로 제공하도록 합니다. 별도의 서버 빌드나 유료 실행기는 사용하지 않습니다.
